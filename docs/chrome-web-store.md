# Chrome Web Store listing

Locale: English (United States)

## Detailed description

Rosewash changes web page backgrounds, text, and neutral borders to a selected
color palette.

- Choose separate light and dark palettes, or follow your system appearance.
- Enable or disable it for individual sites, or pause it everywhere.
- Use the element picker to leave selected parts of a site unchanged.
- Choose installed fonts for English, Chinese, native math formulas, and
  monospace text.
- Optionally dim images and videos when using a dark palette.
- Adjust reading layouts on X and Zhihu with optional width controls.

Keyboard shortcuts let you toggle the current site or pause and resume the
extension. Browser restrictions prevent it from changing internal browser
pages and Chrome Web Store pages.
